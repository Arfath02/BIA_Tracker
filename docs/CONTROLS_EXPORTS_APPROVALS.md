# Collapsible dashboards, Gantt exports and central approvals

This update uses the existing SQL schema v12. Deploy the updated frontend and API together; no new SQL migration is needed if v12 is already installed.

## Expand / collapse

The Project Gantt heading and Portfolio at a glance heading now have labelled Expand/Collapse buttons. Controls expose their state to assistive technologies, work with the keyboard and retain the current selection while collapsed. The Gantt control is available in overview, management and individual project timelines. Collapse state lasts for the current mounted view; it resets when changing to a different scope or signing in again.

## Gantt export

Select the master project, subproject and detail level, then choose PDF, Excel or PNG. Exports include every schedule row in that selection, including rows below/outside the current scroll area. They do not export hidden projects or unrelated workspace data. Export headers identify the selected scope, detail level, scale and current date. The report fits the selected full date range to the output width, rather than capturing the browser's horizontal scroll position.

- PDF: downloadable landscape A4 report, up to 8 rows per page, with progress, current dates, baseline bars, delay colour and milestone markers. Each page repeats the date scale and scope. PDF text is rasterized to retain the browser's Unicode rendering; use Excel for searchable/editable full text.
- Excel: a true .xlsx workbook with Schedule data (all dates, statuses, progress, baseline dates, dependencies) and a coloured Gantt sheet. The Gantt sheet uses up to 60 equal calendar-day buckets to keep large ranges usable; the header identifies each bucket's duration. Original exact dates are retained in Schedule data. Text cells are explicitly stored as strings, not formulas.
- PNG: a downloadable chart image. More than 60 selected rows produces a ZIP containing numbered PNG pages, so browser canvas size limits do not cut off rows.

All export generation is local in the authenticated browser. No chart data is sent to an external conversion service. Up to 5,000 selected rows are supported per export; narrower project scopes are preferable for very large plans. Long image/PDF labels may wrap or be abbreviated by the available row area; full labels remain in Excel.

## Approval routing

New and existing pending budget requests now appear in **Financial control → Approvals** for active Finance and Admin accounts. The notification banner shows how many pending requests the signed-in user can review, excluding their own requests. It opens the inbox directly. The inbox is deliberately across all master projects, irrespective of the dashboard's master-project filter. Filter it to Pending, Approved, Rejected or All.

This is a shared Finance/Admin review queue, not a named-person or email workflow. No email or Teams message is sent. While the app is visible it refreshes every 45 seconds, on focus, and after a save; users can also refresh the page.

Finance reviewers receive only the budget request and a minimal project summary (ID, name, department, currency and approved budget) for projects they cannot otherwise access. The server allows the review decision through this central finance permission. Task, invoice, travel and other project access remains governed by existing project grants. A reviewer must still have normal project access to create a PO or invoice. Self-approval, repeat decisions and stale edits remain blocked. All decisions are audited.
